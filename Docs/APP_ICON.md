# App icon

The app icon was generated with the built-in image generation workflow and
then exported into the complete macOS asset-catalog size set.

## Prompt

> Create a distinctive icon for Norn, a calm native macOS control room for
> resilient services and durable operations. Use an abstract interwoven
> three-node rune suggesting continuity, orchestration, and a protected system
> pulse, with one tiny luminous status point. Make it a premium dimensional
> macOS icon with a midnight navy and charcoal foundation, cool cyan/teal
> edges, and one restrained spring-green healthy-status accent. Keep a bold,
> centered silhouette that remains legible at 32px. No text, letters,
> watermark, device mockup, scene, or fussy detail.

The final edit extends the midnight background to every square corner so the
asset has no external backdrop or white fringe.
